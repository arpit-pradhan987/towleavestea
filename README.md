# Two Leaves and a Bud - Premium Organic Tea Website

A beautiful, modern e-commerce website for Two Leaves and a Bud, featuring premium organic tea blends including ceremonial matcha, chai lattes, and whole leaf teas.

## 🌿 Features

### ✨ Design & Animations
- **Smooth Scroll Animations** - Elements fade and slide into view as you scroll
- **Interactive Hover Effects** - Cards, buttons, and images respond to user interaction
- **Floating Elements** - Logo animations with smooth transitions
- **Staggered Animations** - Sequential reveal of product cards and reviews
- **Mobile Responsive** - Fully optimized for all devices

### 🛍️ Product Showcase
- **Best Sellers Section** - Horizontal scrollable product carousel
- **9 Featured Products** - With ratings, pricing, and quick add-to-cart
- **Product Categories** - Tea Sachets, Gifts & Samplers, Latte Mixes, etc.
- **Search & Filter** - Browse by tea type, mood, and preferences

### 📱 User Experience
- **Smooth Scrolling** - Lenis scroll library for buttery-smooth navigation
- **Navigation Bar** - Sticky header with scroll effects and backdrop blur
- **Mobile Menu** - Hamburger navigation for smaller screens
- **Search Functionality** - Search teas by name
- **Vibe Filters** - Explore teas by mood and lifestyle

### 🎨 Sections
1. **Hero Section** - Eye-catching banner with promotional offer
2. **Best Sellers** - Featured products with carousel navigation
3. **Discover** - Search and filter tea by preferences
4. **Our Origins** - Brand story and core values
5. **Reviews** - Customer testimonials with product recommendations
6. **Cafe & Wholesale** - B2B partnership information
7. **Lattes** - Specialty latte product showcase
8. **Tea Journal** - Blog and educational content
9. **About Us** - Company mission and values
10. **Footer** - Comprehensive navigation and contact info

## 🛠️ Technology Stack

- **HTML5** - Semantic markup with SEO optimization
- **CSS3** - Advanced animations and responsive design
- **JavaScript** - Interactive features and scroll triggers
- **Tailwind CSS** - Utility-first CSS framework (CDN)
- **Lenis** - Smooth scrolling library
- **Remixicon** - Icon library for UI elements
- **Google Fonts** - Custom typography

## 🎯 Animation Classes

- `.fade-in-up` - Fade and slide up animation
- `.reveal` - Intersection observer triggered fade-in
- `.reveal-card` - Scale-in animation for cards
- `.reveal-stagger` - Staggered animation for groups
- `.reveal-left` - Slide in from left
- `.reveal-right` - Slide in from right

## 📱 Responsive Breakpoints

- **Desktop** - Full experience with all features
